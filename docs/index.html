把微信读书的书架
带进 Notion。

翻过的书、划过的句子、随手写下的想法，每天自动整理到自己的 Notion 阅读空间。

开始配置 → 查看 Notion 模板 ↗

重读划线与想法

打开一本书，按章节回顾划线和当时的想法，让摘录保留在原来的阅读顺序里。

看见阅读的积累

从每日快照查看读到了哪一章，用 Notion 原生图表回顾每周、每月和每年的阅读记录。

每天自动同步

复制模板，在自己的 GitHub Fork 配置三个 Secrets。GitHub Actions 默认每天北京时间凌晨四点更新书架。
